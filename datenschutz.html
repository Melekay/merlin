Datenschutzerklärung – Merlin Kalender

Stand: Oktober 2026

Wer die App nutzt

„Merlin Kalender“ ist die Google-Anbindung eines privaten Assistenten. Die App wird ausschließlich von ihrem Besitzer für sein eigenes Google-Konto verwendet. Sie wird nicht öffentlich angeboten.

Welche Daten verwendet werden

Mit der Freigabe „Termine ansehen und bearbeiten“ (Google Calendar, Bereich calendar.events) liest Merlin Termine aus dem Kalender des Besitzers. Auf dessen ausdrücklichen Wunsch legt Merlin Termine an oder ändert sie. Andere Google-Daten werden nicht abgerufen.

Wo die Daten bleiben

  • Die Termine werden nur auf dem privaten Server des Besitzers verarbeitet.
  • Die Termine werden nicht verkauft, nicht für Werbung genutzt und an niemanden weitergegeben.
  • Der Zugangsschlüssel von Google liegt nur auf diesem Server, in einem Ordner, den außer dem Server niemand lesen darf.

Freigabe widerrufen

Die Freigabe lässt sich jederzeit unter myaccount.google.com/connections entfernen. Danach hat Merlin keinen Zugriff mehr auf den Kalender.

Google-Richtlinie

Die Nutzung von Daten aus Google-APIs hält sich an die Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).
